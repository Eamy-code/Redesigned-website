# COREFUTEC リニューアル・ビジュアルデザイン設計 v1.0

2026年10月23日｜企業・採用サイト統合プロジェクト  
状態：**デザイン提案／実装前**。企業ロゴ、写真・人事情報・正式なブランドカラーは公開前に確認。

## 1. コンセプト

**PRECISION MEETS POSSIBILITY｜確かな品質から、その先へ。**

企業サイトのテーマは「精密さ・信頼感・前進」、採用サイトのテーマは「技術・人・成長」です。同じデザインシステムを用いながら、法人トップは実務的な信頼性を、採用トップは発見と期待感を強調します。

Solvvyの参考要素は「大胆なタイポグラフィ」「余白の緩急」「明確な色面」「浮遊感のあるナビゲーション」「スクロールに連動する心地よい動き」です。情報配置、コピー、図形、配色の組み合わせはコアフューテック用に独自設計します。Solvvyの素材・コード・固有表現は転用しません。

## 2. カラー・タイポグラフィ

| トークン | 色・値 | 用途 |
|---|---|---|
| `--navy` | `#101e34` | 主要テキスト、ダーク背景 |
| `--blue` | `#1459f4` | 主CTA、アクセント |
| `--sky` | `#5bd4ed` | ネットワーク図、補助色 |
| `--pale` | `#eaf2ff` | 余白のある淡い背景 |

上記は**リニューアル提案色**です。既存ロゴの正式色との照合後に微調整します。

- 日本語：`Noto Sans JP` 系を第一候補とし、フォールバックにOS標準ゴシック。実装時にライセンスと配信方法を確認。
- 英字：`Inter` 系のニュートラルなサンセリフ。長文には使用しない。
- 企業ヒーロー：PC 約80〜100px、モバイル 約42〜54px。行間1.13〜1.25。
- 通常セクション見出し：PC 約48〜64px、モバイル 約32〜40px。
- 本文：PC 15〜17px、モバイル 14〜16px。行間1.75〜1.9。
- 英語の補助ラベルは約11〜13px、字間を広く。

## 4. 動きの設計

| 動作 | 目的 | 推奨実装 |
|---|---|---|
| ヒーロー見出し | 立ち上がりに品を出す | 下から12〜24px、フェード600〜850ms |
| 抽象ビジュアル | 技術のつながりを示す | CSS/SVGで遅い浮遊、リング・線を動かす |
| セクション表示 | ページの読み進めを補助 | IntersectionObserverでフェード・translate 650ms |
| CTAホバー | 操作できることを示す | 矢印を4px移動、背景色変化180〜250ms |
| カードホバー | 関連性・選択感 | 影の変化と最大3pxの浮上 |
| ナビゲーション | 現在位置・閲覧状態 | スクロール後に薄い影／背景の透明度変化 |

最初に大量のアニメーションを入れるのではなく、ヒーロー・セクション・CTAの3種を中心に統一します。`prefers-reduced-motion: reduce` の場合は動きを停止します。スクロールを邪魔する長時間のローディング演出や自動再生動画は初期版に含めません。

## 5. 企業トップのセクション順

1. ヒーロー：品質・信頼を短いコピーで伝える。CTA「サービスを見る」「相談する」。
2. 信頼の根拠：1983年創業、ISTQB Platinum Partner、独自基準。認定の現況確認が前提。
3. サービス3領域：ソフトウェアテスト、ソフトウェア開発、ソリューション。
4. 強み：独自基準、対応領域、技術者育成など。未検証数値は使わない。
5. 導入の流れとFAQ：初回相談の前に不安を解消。
6. 自社製品：e伝之介くんから製品専用サイトへ。
7. お知らせ／コラム：日付付きで表示。更新は後からWordPress管理。
8. 採用ティザー：採用ページへ明確な入口。
9. お問い合わせCTA：法人用フォームへ。

## 6. 採用トップのセクション順

1. ヒーロー：技術者として成長するイメージを提示。CTA「仕事を知る」「募集要項」。
2. 仕事・人・環境の3入口。
3. 仕事内容：テスト・開発・ソリューション。
4. 社員インタビュー：写真・本人発言・在籍状況を確認してから公開。
5. チーム・環境・研修：旧採用ページの情報を再編集。
6. 募集要項：新卒・中途の条件を分離。正式な求人データを人事に確認。
7. 採用FAQ／選考案内。
8. 応募CTA：採用専用フォームへ。

## 7. 静的制作からWordPressへの引継ぎ

- この提案をHTML/CSS/JavaScriptの静的ページに先に適用します。
- テンプレートの共通化、CSS変数、コンポーネント設計を保持して後からWordPressテーマ化します。
- お知らせ、技術コラム、募集要項、社員インタビュー、FAQは後からCMS管理しやすいフィールドを想定します。
- 現段階の実演はページのデザイン方向性を示すものであり、未制作の下層ページ、実送信フォーム、WordPress編集画面は含みません。
- サイト全ページへ展開する前に、この提案のカラー・タイポグラフィ・ヒーロー・写真の方向性を決定します。

## 8. 公開前に要確認

- 正式な企業ロゴ、ブランドカラー、利用可能な写真・製品画像。
- 認定、役職、事業内容の最新性。
- 社員写真・インタビューの再利用許諾。
- 旧採用募集要項の相違と正式条件。
