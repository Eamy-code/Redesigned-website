## 共通仕様のコード確認

- 日本語はNoto Sans JP、英字はPoppins。青のトークンは `#095cff`。Google Fontsを外部参照しています。
- メガメニューはポインター進入・フォーカス・開閉ボタンに対応し、Escapeで閉じる処理があります。
- モバイルドロワーは開閉時の `aria-expanded` と `inert` を切り替えます。開いている間はbodyのスクロールを抑止します。
- 左からの見出し出現にはIntersectionObserverとクリップを使用します。
- トップのカードは次カードの位置から縮小率・移動量・影を算出し、requestAnimationFrameで更新します。一度きりのフェードではありません。
- マルキーはCSSの連続アニメーションで、ホバー・focus-within時に停止します。
- CSSには950px・680px以下など、下層用CSSには1000px・700px以下の調整があります。
- 軽減モーション指定では、CSSアニメーション・変形を抑制し、JSのカード更新を開始しない定義があります。
- 全19ページが `assets/css/style.css`、`assets/css/page-variants.css`、`assets/js/motion.js` の3ファイルを読み込みます。ページ専用分離は未実装です。
