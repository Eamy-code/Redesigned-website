# 見出しの出現演出

2026年10月26日 ユーザー指定

- 参考サイト：https://solvvy.co.jp/
- ページタイトル、セクション見出し、小見出し、英字ラベルなど、見出しに相当する要素は基本的に左から現れる動きに統一します。
- 「にゅっ」と出てくる感覚を、左からのスライドと左から右へ文字が見えるマスク演出で表現します。透明度だけのフェードにはしません。
- 現行の共通実装は移動距離90px、所要時間1.15秒、終点に向かって減速するイージングです。画面内に入ったときに一度再生します。
- トップの大見出しも左からの出現に揃えます。
- 行やカード全体に同じ演出がある場合、内部の見出しには重ねて適用しません。
- ナビゲーションの文字や装飾文字は一律の適用対象に含めません。
- 動きを減らす設定では演出せず、見出しを表示します。

`design_system_v1_legacy.md` の見出しを下からフェードさせる初期案より、本指定を優先します。`CURRENT_STATE_BASELINE.md` は変更前の記録として保持します。

## オープニングと背景の映像演出

2026年10月26日 追加指定

- 参考サイト：https://recruit.solvvy.co.jp/
- サイトを開いた際にごく短いオープニング映像・アニメーションを表示し、その後にサイト本体を見せます。
- サイト本体のメインビジュアルでは、背景映像をループさせる演出を取り入れます。
- 背景映像の上にコピーや導線を重ね、文字の読みやすさを確保します。
- 実装時は無音での自動再生とスマートフォンでのインライン再生を想定します。再生できない場合は静止画でサイトを表示し、閲覧を止めません。
- 動きを減らす設定ではオープニングを省略し、背景は静止画にします。
- 動画素材、適用ページ、冒頭の秒数、初回だけ再生するか、スキップ方法は未確定です。参考サイトの映像素材は転用しません。
- 現時点では制作要件への追加のみです。動画素材はプロジェクト内に見当たらず、映像演出は未実装です。

初期案の「自動再生動画を初期版に含めない」という方針より、今回の追加指定を優先します。
