# CORE FUTEC / Motion-led Design Prototype v4

> **Codexで現行情報を反映する場合：** 最初に `CODEX_MASTER_PROMPT.md` を読み、記載の順序と制約に従ってください。`docs/` に旧URL調査、統合サイトマップ、初期デザイン検討資料を収録しています。初期デザイン資料は現在のv4と一部異なるため、見た目の判断は `DESIGN_VARIATION_MAP.md` と現在の実装を優先してください。

## この成果物の位置付け

Solvvyの**余白・英字見出しの緊張感・ブランドブルー・メガメニュー・スクロール演出**を実サイトで観察したうえで、コアフューテック向けに独自にデザインした、企業・採用サイト統合の**静的デザイン試作**です。Solvvyのコードや文章、画像を複製したものではありません。

`dist/index.html` をブラウザーで開くと表示できます。全ページ、リンク先は相対パスなのでファイルとして直接開けます。インターネット接続があると Google Fonts（Poppins / Noto Sans JP）が使用されます。未接続時はシステムフォントにフォールバックします。

## 試作に含むもの

- デスクトップ：ナビ項目ホバー・フォーカスで開く、各下層ページへの本物のリンクを持ったメガメニュー
- モバイル：開閉可能なドロワー、Escapeキー、フォーカス操作
- 左から**スライド＋クリップで現れる**見出し（IntersectionObserver）
- 右から左へ途切れず流れる英字マルキー。ホバーで一時停止
- **実スクロール量に追従するカード重なり演出**。次のカードが手前に来ると先行カードが縮小・移動
- サービス行とCTAのホバー、強調されたページ遷移
- トップ＋企業/採用の主要下層ページを含む相対リンク付き静的HTML
- `prefers-reduced-motion` への対応

## 生成・変更

```bash
node build.mjs
```

- `build.mjs`: 静的HTMLのページ構造、文言とナビゲーションの元データ
- `assets/style.css`: デザインシステム・レイアウト・アニメーション
- `assets/page-variants.css`: 下層ページごとのレイアウト・色・文字組み・固有の図案
- `assets/motion.js`: メガメニュー・モバイルナビ・スクロール連動制御
- `dist/`: 配布できる静的サイト一式
- `DESIGN_VARIATION_MAP.md`: 19ページに対するデザインの使い分け一覧

## v4の重要な変更

初期試作の下層ページは、共通ヒーロー＋同じカード型リストの繰り返しでした。v4では**10種類の表示類型**を用意し、同じフォント・グローバルナビ・CTAを保ちながら、各ページの構成・背景・情報密度・固有のビジュアルを変えています。詳細は `DESIGN_VARIATION_MAP.md` をご覧ください。

## WordPress移行設計

HTML構造とCSS/JSはWordPress化しても再利用可能です。`header.php`、`footer.php`、`front-page.php`、`page.php`、`archive.php` などへ分割し、ページ固有データをテンプレートに流し込みます。JSはテーマのアセットとして登録し、WordPressの管理画面から変更する記事・採用募集内容・企業情報・CTAをACF等のフィールドへ移します。
